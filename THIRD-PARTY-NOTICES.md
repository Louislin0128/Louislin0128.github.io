## oneko.js

The animated cat widget and its sprite are from [adryd325/oneko.js](https://github.com/adryd325/oneko.js). The project is distributed under the MIT License. Its copyright and permission notice are preserved in [`assets/vendor/oneko/LICENSE`](assets/vendor/oneko/LICENSE).

The script is included locally for GitHub Pages compatibility; this site does not fetch the widget at runtime from a third-party server. The original project describes the widget as a cursor-following cat and provides the sprite as `oneko.gif`.

The local copy adjusts the initial spawn point to the lower-right area so the cat does not cover the brand mark on page load. The upstream MIT notice remains intact.
